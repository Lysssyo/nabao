# 纳宝管理端（Vue 3）

Vue 3 + TypeScript + Vite，部署在后端 `/admin/index.html`，没有 CDN 依赖。管理端可以查看投票额度、立即发起真实采集、查看定时检查和任务状态，以及登录自己的小红书采集账号。作者管理支持新增和移除，初始保留现有五位作者。

## 分层

| 目录 | 职责 |
| --- | --- |
| `src/api` | 同源 HTTP、管理鉴权、超时、错误分类；不保存密钥 |
| `src/domain` | 接口类型、数据校验、投票结果展示、额度排序与状态文案 |
| `src/composables` | 会话内存、请求代际、单任务轮询、登录图片生命周期 |
| `src/components` | 连接、额度表、采集状态、作者管理、采集账号组件 |
| `src/pages` | 页面组合与用户操作绑定 |
| `src/styles` | 桌面和移动端样式，额度表固定首列并横向滚动 |
| `tests` | 排序边界、真实组件渲染、鉴权/超时/竞态、采集与登录流程 |

## 开发与构建

要求 Node >= 22.12，后端默认运行于 `http://127.0.0.1:18081`。

```sh
cd frontend
npm ci
npm test
npm run build
npm run dev
```

`npm run build` 先进行 TypeScript 校验，再构建到 `dist/`，最后将产物同步至 `backend/src/main/resources/static/admin/`。该后端目录只包含本前端的生成文件，**不要手动编辑**。同步时删除旧产物，避免同时保留旧版实现。生成文件纳入版本控制，使 Maven 和现有后端容器构建不依赖在线 Node 下载；CI 会重新构建并校验产物一致，再打包 Java。修改源码后须运行构建并一并提交产物。

`npm run dev` 的 Vite 地址为 `/admin/`，`/internal` 请求代理到本机后端。生产 CSP 禁止内联脚本与样式；开发热更新如被生产 CSP 拦截，应使用 `npm run build` 后通过后端验收。

## 操作与状态

- **刷新结果**只读取已发布的投票表与采集状态。
- **作者管理**填写昵称和完整小红书主页链接新增，移除时在对应行确认。配置保存在采集器，重启保留；增删不会自动采集或改写历史摘要。支持0～50位，少于两位时提示补充并禁止采集，服务忙时禁改。
- **立即采集**通过 `POST /internal/v1/collector/runs` 发起真实任务；采集完成时自动重新读取额度表。无当日新表时保留已发布数据与真实日期，不宣称发布了新表。
- 登录区用 `POST /login` 创建登录任务。二维码/登录页面通过带鉴权的 `/login/preview` 读取 PNG，再用临时 blob URL 显示；不存在带密钥的图片 URL。
- 用户扫码并完成本人验证后点击“已完成登录”；后端验证实际登录后才保存会话。未完成验证的 409 保留登录页供继续操作。
- “检查登录状态”请求 `/session/check`。失效时重新登录；页面显示的是服务实际返回的状态。
- 服务忙时禁止再次提交。状态轮询在上次请求完成后才安排下次，忙时 4 秒、空闲时 15 秒；读取状态/图片（含响应体）最长 25 秒，登录确认等变更最长 65 秒；不自动重试变更请求。
- 管理密钥仅存在当前页面内存；断开、页面隐藏卸载事件 `pagehide`、鉴权/网络/数据错误会清空。请求取消与代际判断保证迟到响应不会恢复旧数据。二维码在完成、取消、断开、卸载时释放。
- 不存 localStorage/sessionStorage，不在日志或 URL 输出管理密钥，不把远端字符串当 HTML 渲染。

小红书返回访问限制时显示“访问受限”并停止采集，不显示扫码或完成登录按钮。失败页 PNG 仅获取一次供核对，不自动重试登录；用户可在处理网络/站点限制后手动检查或重新尝试登录。

生产部署需要后端连接 collector control 服务。该服务不可用时，投票结果仍可浏览，手动采集和登录操作不可用。
