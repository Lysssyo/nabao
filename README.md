# nabao

用于记录跨渠道基金定投、查看公开额度变化并前往渠道处理的 iOS 工具。

个人计划留在手机本地。后端处理公开额度信息和匿名通知订阅；采集器负责追踪指定的小红书作者。没有用户账号或个人计划云同步。

当前简化版由管理端配置的作者按基金、日期、字段分别投票，初始名单为美基搭子、老纳、纳宝、纳普NaS&P（1572871865）、纳指雷达（94168796616）。每作者每字段最多一票，唯一最高且至少两票采用，平票/单源显示待更新。采集器输出日期 JSON 和 `latest.json`，额度数据不写数据库；后端只读文件，iOS 只展示最终表格。范围固定为41个纳指100份额。

模型由采集器配置和调用。采集、抽取、归一化、发布各自保留状态；未通过的真实额度不会写成可用结果。

最新五源实际表日期为 **2026-10-23**：41份额、205字段中163个采用、42个待更新。10/24采集不改变原图日期；平票和未知口径保留待更新。真实文件、独立18081后端和模拟器共用同一表，详见验证记录。

10/25管理端改为Vue 3并适配移动端，提供作者增删、立即采集、定时任务状态和本人小红书采集账号登录。网页、iOS列表按代销额度倒序，附条件额度保留原文并单独排列。Java分为接口、应用、领域与基础设施；Vue分为API、领域规则、状态编排、组件和页面；iOS分为入口、功能、服务与共享组件。iOS截图导入位于计划页右上角“＋”，设置顶部可保存后端地址。

10/25本机已恢复小红书登录，并验证重启服务后无界面检查仍为已登录。登录判断兼容站点当前字段，原正式会话在取消或失败时保留；遇平台访问限制仍暂停自动采集。此次登录修复没有重新发布额度表。

## 目录

- `ios/`：SwiftUI 客户端、截图识别和本地计划。
- `backend/`：每日表只读 API 和匿名通知；旧观察接口保留兼容。
- `collector/`：作者发现、正文/配图采集及模型接入。
- `frontend/`：Vue管理端源码、移动适配和行为测试。
- `docs/contract.md`：第一版边界与组件接口。
- `.local/`：本地测试输入和运行证据，不进入 Git。
