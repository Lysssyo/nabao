## 远程通知验证边界

个人计划继续保存在本机。服务端登记匿名安装身份和 APNs token，仅推送“公开参考额度有更新，请打开纳宝核对定投”；用户点击后才在本机核对个人计划。没有把个人金额或截图发送到服务端。

本地脚本使用临时生成的 P-256 密钥、虚构设备 token 和隔离数据库，独立校验 Java 实际生成的 JWT 签名。首次登记不通知历史额度；重复快照不重复发送；模拟 503 后重启实际 JAR，待发送状态仍在，等待原定退避后成功；Swift 客户端连续两次退订成功，后续变更没有发送。原 8080 数据库不参与这些合成数据测试。

Apple 配置仍未提供。模拟器载荷注入验证了系统通知展示和点击路由；本地 HTTP 模拟服务验证了请求内容和重试逻辑。这两项均不代表 Apple 的 HTTP/2/TLS 请求、真实 token 注册、APNs 接受或 iPhone 实际送达已通过。真实设备测试按用户要求暂缓。
