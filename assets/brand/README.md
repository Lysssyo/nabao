# 纳宝标志

`nabao-icon.png` 为两端共用的1024×1024、不透明PNG母版，来自用户2026-10-25确认的深绿／米白／金色设计。网页尺寸副本位于 `frontend/public/brand/`；iOS副本位于 `ios/App/Assets.xcassets/AppIcon.appiconset/`。iOS由系统裁圆角，母版四角保留完整底色。

制作方式：内置 imagegen，基于确认稿编辑；仅用 macOS sips 导出所需尺寸。

最终编辑提示词：

> Edit target: the approved Nabao branding board. Produce the production iOS app icon asset only, square 1024 x 1024. Extract and faithfully reproduce the RIGHT-HAND app icon design: EXACT same ivory folded storage-container/N symbol, exact same muted-gold diamond and negative space, same proportions and placement. Do not reinterpret or redesign the symbol. The dark evergreen background of that icon must now cover the ENTIRE square canvas edge-to-edge, including all four corners: NO rounded-square outer silhouette, NO exterior ivory margins, NO border. iOS will apply its own corner mask later. Keep the original symbol's relative size around 65 percent of the square and centered optically. Flat clean solid evergreen #145C4B, ivory #F6F5EF, gold #C7A266, crisp vector-like edges, no texture, no gradients, no shadows. NO text, no additional marks, no presentation board. Preserve the distinctive angled left container stroke, tall rounded right stroke, narrow open bottom slit, and the floating gold diamond exactly as in the approved right icon. Output one opaque square icon ready for an asset catalog.
